Ten kart concepts

Every kart carries a side-mounted Yamaha R15 V2 on the right, a chromoly frame and the full safety kit. Each was generated from the team's steering sketch and checked automatically against the rulebook's vehicle requirements, plus a clash scan with the front tyres swept through full lock.

Getting SLDPRT files

  1. SolidWorks: Tools › Options › System Options › Import, untick Enable 3D Interconnect.
  2. Tools › Macro › New, then in the VBA editor File › Import File and choose solidworks_macro/EKVC_STEP_to_SLDPRT_and_SLDASM.bas. Run main.
  3. Paste the path of the repository's output folder. The macro saves an .SLDPRT next to every STEP part and builds <style>.SLDASM for all ten karts.

Quick route for one kart: open output/<style>/<style>_ASSEMBLY.step in SolidWorks and use Save As. Branch claude/kind-brahmagupta-vfebio of trafarsh/ekvc-gokart-cad.
