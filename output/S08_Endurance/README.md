# S08 - Endurance

Heavily triangulated with upper side rails and diagonal floor braces; built for the endurance event.

* Wheelbase **47.00 in** (1193.8 mm), front track 37.50 in, rear track 42.80 in
* Frame: `endurance` - 20.7 m of 25.4 x 1.65 mm AISI 4130 chromoly, seamless (C 0.28-0.33 %) (~20.0 kg tube)
* Bumpers: front `U`, rear `U`, side `double`; body: nose `round`, pods `full`
* Steering: arm 155 mm at 15.25 deg, tie rods 277/396 mm (solver), lock inner 33.9 / outer 25.2 deg, R(outer front) 2.81 m, Ackermann 99 %
